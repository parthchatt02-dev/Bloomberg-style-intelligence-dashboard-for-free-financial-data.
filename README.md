# Bloomberg-style-intelligence-dashboard-for-free-financial-data.
Runs locally. One data layer (OpenBB Platform — 50+ providers, 270 endpoints), one amber-on-black terminal UI, and a built-in rules engine that turns numbers into signals so you don't stare at raw data trying to remember what matters.  Built on OpenBB + Vite + React + TypeScript + TradingView lightweight-charts.
